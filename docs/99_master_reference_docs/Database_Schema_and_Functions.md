# Database Schema and Serverless Functions Reference

This document serves as the master reference map for all PostgreSQL tables and Supabase Edge Functions utilized across the Nonna App infrastructure.

## 🗄️ Tables Summary

| Table Name | Purpose |
| ---------- | ------- |
| `profiles` | Extended user profiles linked to Supabase Auth (`auth.users`). |
| `baby_profiles` | Core profiles representing the babies being tracked. |
| `baby_memberships` | Core role-based access control (RBAC). Links `profiles` to `baby_profiles` with roles ('owner', 'follower', 'admin'). |
| `photos` | Records for uploaded baby photos/videos, storing storage paths and metadata. |
| `photo_comments` | Social discussion threads on specific photos. |
| `photo_tags` | Tag definitions linking users to photos. |
| `photo_squishes` | Gamification ("likes") for photos. |
| `registry_items` | Wishlist/registry items created by owners. |
| `registry_purchases` | Immutable audit trail marking who bought which registry item. |
| `events` | Calendar milestones and event scheduling records for babies. |
| `event_rsvps` | Attendance tracking for events. |
| `event_comments` | Social discussion threads on specific events. |
| `name_suggestions` | Gamification block for proposing baby names before birth. |
| `name_suggestion_likes` | Upvotes/downvotes on name suggestions. |
| `invitations` | Secure, token-based invites generated by owners to add followers. |
| `notifications` | In-app alert history and unread status markers. |
| `tile_configs` | Dynamic layout positions and visibility parameters for individual UI widgets. |
| `screen_configs` | Configuration definitions determining global screen layouts. |
| `user_stats` | Gamified participation scores per user. |
| `owner_update_markers` | Sync timestamps assisting offline-first cache invalidation mechanisms. |

## 📋 Table Definitions (Columns & Usage)

### `profiles`
| Column | Type | Constraints | Description & Usage |
|---|---|---|---|
| `id` | uuid | PK, FK(`auth.users`) | Matches Supabase Auth user ID. |
| `email` | varchar(255) | UNIQUE | User's email address. |
| `first_name` | varchar(100) | | User's first name. |
| `last_name` | varchar(100) | | User's last name. |
| `avatar_url` | varchar(1000) | | Path/URL to profile picture. |
| `preferences` | jsonb | DEFAULT '{}' | Custom UI/notification settings. |
| `created_at` | timestamptz | DEFAULT now() | Profile creation timestamp. |
| `updated_at` | timestamptz | DEFAULT now() | Last profile modification timestamp. |

### `baby_profiles`
| Column | Type | Constraints | Description & Usage |
|---|---|---|---|
| `id` | uuid | PK | Unique identifier for a baby setup. |
| `name` | varchar(100) | | Name or nickname of the baby. |
| `due_date` | date | | Expected or actual date of birth. |
| `gender` | varchar(20) | | Assumed gender (if applicable). |
| `cover_photo_url` | varchar(1000)| | Path/URL to the baby's main banner. |
| `settings` | jsonb | DEFAULT '{}' | Privacy and module visibility settings. |
| `created_at` | timestamptz | DEFAULT now() | Creation date. |

### `baby_memberships` (RBAC)
| Column | Type | Constraints | Description & Usage |
|---|---|---|---|
| `id` | uuid | PK | Unique membership record. |
| `user_id` | uuid | FK(`profiles`) | The user being granted access. |
| `baby_profile_id` | uuid | FK(`baby_profiles`) | The target baby profile. |
| `role` | varchar(20) | CHECK (role in 'owner','follower','admin') | The access level granted. |
| `created_at` | timestamptz | DEFAULT now() | When access was granted. |

### `photos`
| Column | Type | Constraints | Description & Usage |
|---|---|---|---|
| `id` | uuid | PK | Unique photo record identifier. |
| `baby_profile_id` | uuid | FK(`baby_profiles`) | Which baby this photo belongs to. |
| `uploaded_by` | uuid | FK(`profiles`) | Who uploaded the asset. |
| `storage_path` | varchar | NOT NULL | Supabase Storage explicit path (`s3://...`). |
| `caption` | text | | User-provided text description. |
| `captured_at` | timestamptz | | Original EXIF or selected date. |
| `metadata` | jsonb | DEFAULT '{}' | Dimensions, EXIF, orientation data. |

### `registry_items`
| Column | Type | Constraints | Description & Usage |
|---|---|---|---|
| `id` | uuid | PK | Unique item requirement entry. |
| `baby_profile_id` | uuid | FK(`baby_profiles`) | Target baby. |
| `created_by_user_id`| uuid | FK(`profiles`) | Parent/owner who listed it. |
| `name` | varchar(200) | NOT NULL | E.g., "Stroller". |
| `description` | text | | Additional context/sizes. |
| `link_url` | varchar(2000)| | External URL to purchase. |
| `priority` | integer | DEFAULT 3, 1 to 5 | How badly the item is needed. |

### `registry_purchases`
| Column | Type | Constraints | Description & Usage |
|---|---|---|---|
| `id` | uuid | PK | Unique purchase entry. |
| `registry_item_id`| uuid | FK(`registry_items`) | Which item the user purchased. |
| `purchased_by_user_id`| uuid | FK(`profiles`) | The user committing the gift. |
| `note` | varchar(500) | | Optional gift message to the family. |
| `purchased_at` | timestamptz | DEFAULT now() | Time the gift was marked bought. |

### `events`
| Column | Type | Constraints | Description & Usage |
|---|---|---|---|
| `id` | uuid | PK | Unique event entry. |
| `baby_profile_id` | uuid | FK | Associated baby. |
| `created_by` | uuid | FK | Owner who scheduled it. |
| `title` | varchar(200) | NOT NULL | E.g., "Baby Shower". |
| `description` | text | | Full details. |
| `event_date` | timestamptz | NOT NULL | Scheduled time. |
| `location` | varchar(500) | | Text address or map coordinates. |
| `is_public` | boolean | DEFAULT true | Visible to all followers, or restricted. |

### `invitations`
| Column | Type | Constraints | Description & Usage |
|---|---|---|---|
| `id` | uuid | PK | Unique invite record constraint limit. |
| `baby_profile_id` | uuid | FK | Which baby the user is invited to. |
| `invited_by` | uuid | FK(`profiles`) | Who dispatched the invite. |
| `email` | varchar(255) | NOT NULL | Recipient's email. |
| `role` | varchar(20) | DEFAULT 'follower' | Target permission role. |
| `token` | varchar(64) | UNIQUE, NOT NULL | Secure join code for deeplinking. |
| `status` | varchar(20) | 'pending', 'accepted' | Completion lifecycle state. |
| `expires_at` | timestamptz | NOT NULL | TTL (e.g., 7 days strictly). |

### `notifications`
| Column | Type | Constraints | Description & Usage |
|---|---|---|---|
| `id` | uuid | PK | Alert identifier. |
| `user_id` | uuid | FK | The recipient of the alert. |
| `baby_profile_id` | uuid | FK | Context context (if navigating). |
| `type` | varchar(50) | NOT NULL | Topic routing (e.g., 'new_photo', 'rsvp'). |
| `title` | varchar(200) | NOT NULL | Direct string alert header. |
| `body` | text | NOT NULL | Extended text breakdown alert context. |
| `data` | jsonb | DEFAULT '{}' | Navigation parameters (e.g., `eventId`). |
| `is_read` | boolean | DEFAULT false | Badge consumption flag. |

### Configuration Tables (`tile_configs` & `owner_update_markers`)
| Table / Column | Usage & Role |
|---|---|
| `tile_configs` | Stores JSON setups outlining if and where widgets (e.g., Timeline, Countdown) appear on specific screens per user role. Overrides remote flags. |
| `owner_update_markers` | Specialized offline DB layer. Captures `(baby_profile_id, component, updated_at)` to let `CacheManager` efficiently invalidate `isDirty` cached nodes without pinging everything. |

## ⚡ Serverless Edge Functions

| Function Name | Purpose | Details |
|---|---|---|
| `send-push-notification` | Dispatches external REST API calls to **OneSignal**, targeting native device push deliveries dynamically for specific Supabase User IDs. | Resolves specific `targetUserIds`, passes them out of the backend securely via `ONESIGNAL_APP_ID`. Used heavily for instant alerts (e.g., new photos). |
| `send-invitation-email` | Handles dynamic, structured HTML email dispatchations via the **Resend API**. | Captures invitation requests, templates family/baby names, appends unique deep linking `inviteUrl` tokens, and delivers them externally. |
| `generate-thumbnail` | Asynchronous image/media downsizing processor (backend simulation/stub hook). | Would automatically kick off downsizing assets written to Supabase Storage before persisting back into a bucket. Hooked directly via trigger sequences upon S3 uploads. |
| `image-processing` | Broad multi-step asset API. Extracts strict metadata dimensions, orientations, EXIF extraction, & optimization passes. | Validates content safety and parses image geometries to enhance front-end container clipping (avoids flutter layout snapping jump). |
| `notification-trigger` | OneSignal backend queue multiplexer module. | Mass broadcasts segmentations. Intelligently filters unbanned players versus external user IDs before distributing payloads. |
| `tile-configs` | Configuration aggregator endpoint. Resolves deep JSON blobs enforcing the app's modular block visibility and role protections dynamically. | Merges base user permissions with global Firebase visibility strings and Supabase custom role settings into one cohesive return map. |
